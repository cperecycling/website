# CPER Complete Website Package

This is a complete static replacement site for cperecycling.ca.

## Included
- English homepage and core service pages
- French homepage and core service pages
- Dedicated data destruction and ITAD pages
- What We Recycle and Sell to Us pages
- Community impact pages
- Service-locations directory
- 17 location landing pages for SEO
- Contact/pickup pages
- Privacy pages
- 404 page
- Shared responsive CSS and JavaScript
- Local copies of CPER imagery
- robots.txt and sitemap.xml
- Schema.org Organization / Service markup

## Upload
Upload the contents of this folder to the web root for cperecycling.ca. `index.html` should be at the site root.

## Important before going live
1. The forms are intentionally static and open the visitor's email client addressed to info@cperecycling.ca. If your existing site uses a form endpoint, replace the `.mailto-form` behavior in `assets/js/site.js`.
2. Review service-area claims and location availability before publishing. Dallas–Fort Worth is explicitly shown as partner-served.
3. CPER is described as a registered non-profit, not a registered charity; no charitable tax-receipt claim is made.
4. The package uses NIST SP 800-88 Rev. 2 aligned wording for data sanitization. Confirm your operational process remains aligned before publishing.
5. If you install analytics, a CRM, cookies or third-party form processing, update the privacy policy accordingly.

## Design direction
The site uses a warmer, community-first layout inspired by the clarity and approachability of established non-profit electronics recyclers, while keeping CPER's own brand, copy, services and visual identity.
