# CPER Website - Complete Package

This is a deployable static website package for cperecycling.ca.

## Main files
- `index.html` — latest homepage
- `sell-to-us.html` — latest Sell to Us page
- `service-locations.html` — service locations page
- `what-we-recycle.html` — accepted electronics page
- `styles.css` — shared site styling
- `script.js` — site interactions
- `assets/` — logo and site imagery

Upload the contents of this folder to the root of the GitHub Pages repository.

## Bilingual English / French pages
The site includes matching English and French Canadian pages with an EN | FR switch in the header:
- `index.html` ↔ `index-fr.html`
- `service-locations.html` ↔ `service-locations-fr.html`
- `what-we-recycle.html` ↔ `what-we-recycle-fr.html`
- `sell-to-us.html` ↔ `sell-to-us-fr.html`

Each language version links to its equivalent page and includes `hreflang` alternate links for search engines.
