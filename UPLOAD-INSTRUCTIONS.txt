CPER GITHUB PAGES - FLAT VERSION

THIS VERSION HAS NO FOLDERS.

Every HTML file, image, stylesheet, JavaScript file and city page is in this ONE folder.

HOW TO UPLOAD:

1. Extract CPER-GitHub-FLAT.zip on your computer.
2. Open the extracted CPER-GitHub-FLAT folder.
3. Select ALL files inside it.
4. In GitHub, open:
   https://github.com/cperecycling/website
5. Choose Add file > Upload files.
6. Drag ALL selected files into the upload page.
7. Commit the changes.

IMPORTANT:
- You do NOT need to create an assets folder.
- You do NOT need to create a locations folder.
- styles.css must be visible at the repository root.
- script.js must be visible at the repository root.
- index.html must be visible at the repository root.
- photos such as logo.png, community.jpg and laptops.jpg must be visible at the repository root.
- city pages such as calgary.html and toronto.html must also be visible at the repository root.

Because this version is completely flat, GitHub's browser uploader cannot accidentally skip nested folders.

After the commit finishes, wait about 1-3 minutes and hard-refresh the website with Ctrl+F5.
